# サイトカード・宣伝文の調査と提案

確認日: 2026-09-11。比較ページ: [card-lab.html](../card-lab.html)。

## 今回の提案

現在のカードは、ピンクの装飾、太い大見出し、ボタン風の帯、正面の女性写真が重なる。これが広告を連想させやすいという制作上の見立てから、短い問い・余白・控えめな色を中心とした10案を作った。女性写真あり・なしを各1枚、計20枚。写真ありは全て既存の `female_011`（架空の成人女性、25歳）を使用する。

第一候補は01「なぜか、目で追ってしまう顔。」、自然さを優先するなら03「好みって、案外知らない。」、コード導入と組み合わせるなら08「8つの『好き』。あなたは、どれ？」。これは制作上の推奨であり、CTRの実測結果ではない。

全案で、写真なしでも「好みの顔タイプ診断」と分かるようにする。入口で好奇心を作り、結果カードではコード・名前・一文を明快に示す。所要時間・的中率・利用者数など、未確認の実績は宣伝文に足さない。07・08・10は3文字コード導入後の先行案。

## 調査の限界と比較の仕方

観察対象は現在のトップページのOGP。実際の結果カードやSNS投稿は別の表現を持つ場合があり、混同しない。利用者数は診断全体の数字で、画像によるクリック率・拡散率は未確認。カードの写真あり・なし、神秘的な表現の効果は実測していない。

採用を判断するなら、まず同一コピーの01A/01Bで写真の有無を比べ、次に01/03のコピーを同条件で比べる。入口のクリックだけでなく、診断開始・完了まで見て、期待した体験と合っているかを確認する。本ページから実際のSNSへの投稿は行わない。投稿内の表示は比較用モックで、XやLINEでの実表示を保証しない。

## 3文字・8タイプの提案

| 桁 | 2つの印象 | 説明 |
| --- | --- | --- |
| 1 | A / Airy（軽やか）、R / Refined（落ち着き） | 全体の雰囲気。年齢差で表さない |
| 2 | S / Soft（柔らか）、C / Crisp（凛と） | 顔立ちから受ける印象 |
| 3 | Q / Quiet（さりげなさ）、V / Vivid（華やか） | 印象の強さ |

| コード | 新しい呼び名の案 | 女性現分類への仮対応 | 男性現分類への仮対応 |
| --- | --- | --- | --- |
| ASQ | 木漏れ日の顔 | キュート | チャーミングソフト |
| ASV | 陽だまりの顔 | アクティブキュート | チャーミングハード |
| ACQ | 風のような顔 | フレッシュ | フレッシュソフト |
| ACV | きらめきの顔 | クールカジュアル | フレッシュハード |
| RSQ | 余韻のある顔 | ソフトエレガント | エレガントソフト |
| RSV | 花ひらく顔 | フェミニン | エレガントハード |
| RCQ | 月明かりの顔 | クール | クールソフト |
| RCV | 星を射る顔 | エレガント | クールハード |

この対応は**表示案であり、顔立ちとして検証済みの分類ではない**。特に既存の女性分類は、厳密な3二択の直積ではない。新コードを正式採用するには、男女各40枚について3軸と既存タイプの一致を確認し、合わなければ軸または対応を見直す。全員25歳という前提は維持する。顔から性格や実際の相性を推定するものではない。

採点は既存のタイプ別投票を維持し、決まったタイプIDにコードを対応させる方法を想定。3軸をそれぞれ多数決で確定する方法だと結果が変わるので、それは別の仕様変更になる。同点の均等抽選・保存方式も維持。本ページでは分類コードを本番へ導入していない。
