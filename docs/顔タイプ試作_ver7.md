# 顔タイプ試作 ver7 — 男女各8タイプ

[写真比較HTML](face-types-v7.html) / [所属タイプ・使用した全プロンプト](../data/previews/face_types_v7.js)

男女それぞれ8タイプに対して、新しい架空の成人を1人ずつ生成する比較用サンプル。従来のパーツ数値から人物を組み立てる方法を改め、人物全体の印象を中心にキャスティングした。全員が美男美女であることと、タイプごとに顔の印象を大きく変えることを生成目標とした。

## 分類と制作方針

分類はHibiscusの[女性8タイプの記事](https://hibiscus0501.com/facetype-entertainers100/)と[男性8タイプの記事](https://hibiscus0501.com/mens-face-type-entertainers/)を参考にしている。タイプ名は生成目標・制作上の分類であり、人物に対する専門家の診断結果ではない。

| --- | --- | --- |
| 001 | キュート | チャーミングソフト |
| 002 | アクティブキュート | チャーミングハード |
| 003 | フレッシュ | フレッシュソフト |
| 004 | クールカジュアル | フレッシュハード |
| 005 | フェミニン | エレガントソフト |

| 007 | エレガント | クールソフト |
| 008 | クール | クールハード |

甘い童顔、目力の強い若々しい顔、あっさりした顔、シャープな顔、曲線的な大人顔、控えめな大人顔、彫りが深い華やかな顔、強い骨格の顔という全体の違いを優先した。生成モデルの平均的な美形への収束を減らすため、プロンプトには必要な範囲の形容を含めている。形態の数値・特徴量タグは作成していない。

正面・目線の高さ・ニュートラルなスタジオ背景・柔らかな照明・無地のアイボリーの服を共通とした。全員成人の日本人を指定し、実在の芸能人名や参照写真は生成に使用していない。ver6計画の共通前髪・輪郭などの制約は新しい試作には引き継がず、タイプに合う髪型も許容した。顔の違いを見比べられるよう、HTMLに顔の拡大比較とタイプ名の非表示を用意した。

## データと採点

ブラウザglobalは `window.FACE_TYPE_PREVIEW_V7`。16人全員のレコードと生成指示を用意してから、内蔵 `image_gen` で1人ずつ個別に新規生成した。実行した全指示は各レコードの `prompt`、出力ファイル名・画像ハッシュ・プロンプトハッシュは `generation` に記録する。CLI/APIでの画像生成は使用していない。

各レコードは `id`・`gender`・`type`・`label`・`description`・`image`・`prompt` と生成記録を持つ。`tags`・`shape_features`・`appearance_features` は持たない。`label` と `description` は比較HTMLの表示用であり、採点入力には使わない。

今後の採点では選んだ人物の `type` に1点を加える。男女のタイプ集合はそれぞれ独立して扱う。このHTMLは画像を比較する段階の成果物で、本番診断は引き続きver6.1を使用する。診断画面へ組み込む際は選択カードを画像のみとし、タイプ名や説明を表示しない。

## 保存と取り込み

画像は `assets/previews/v7/<gender>/<id>.png`。すべて既存の [normalize_face_asset.py](../scripts/normalize_face_asset.py) で1200×1600・顔中心に正規化する。取り込みは次のコマンドで画像と生成記録を同時に更新する。

```bash
.venv/bin/python scripts/import_face_type_v7.py --id female_001 --input /path/to/generated.png
python3 scripts/build_pages.py
```

[整合性確認](../scripts/check_integrity.py)で男女各8タイプ、画像の有無と一対一対応、PNGサイズ、画像・プロンプトのハッシュ、顔検出を確認する。ビルド後は `dist/docs/face-types-v7.html` に配置され、Cloudflare Pagesに公開される。

## 確認結果

- 16枚を通常表示と顔の拡大表示で目視比較し、全画像の取り込み後に正面顔検出・1200×1600 PNG・異なる画像ハッシュを確認した。
- 幅1440pxと390pxのブラウザで、全16枚の読み込み、男女の切り替え、タイプ名の非表示、拡大ダイアログ、前後の写真への移動、キーボード操作、フォーカス復帰を確認した。横はみ出し、ブラウザ例外、HTTPエラーはなかった。
- `npm test` の既存10テストと `python3 scripts/build_pages.py` が成功した。
