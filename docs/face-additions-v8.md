# v8追加候補 — 男女各8タイプに5人ずつ

[既存80人＋追加候補80人の比較HTML](face-types-additions.html) / [追加80人の全プロンプト・生成記録](../data/previews/face_additions_v8.json)

既存のv8と同じ方法・撮影条件で、女性40人・男性40人を追加生成した。各タイプは既存5人と追加5人の計10人となり、比較ページには160人を掲載する。追加分は確認用であり、診断には未採用。本番の写真・データ・二択・採点・結果・共有ページは引き続き既存80人を使用する。

## 生成条件

既存レコードの全プロンプトを引き継ぎ、`Independent identity brief` を新しい人物設定に置き換えた。全80人分を生成前に [prepare_face_additions.py](../scripts/prepare_face_additions.py) でJSONへ確定してから、内蔵 `image_gen` を人物ごとに個別に呼び出す。既存写真の編集・髪型の差し替え・集合写真の分割は行わない。

全員を架空の成人日本人・25歳と指定する。輪郭、目の形や配置、鼻、口の組み合わせに人物ごとの違いを持たせ、年齢差でタイプを表現しない。正面の顔と肩、直接の視線、目線の高さのカメラ、ニュートラルな薄い暖色グレーのスタジオ背景、柔らかな照明、無地のアイボリーの服、控えめな閉口表情、文字・透かしなしという条件も既存と同じ。

生成画像は [import_face_addition.py](../scripts/import_face_addition.py) から既存の [normalize_face_asset.py](../scripts/normalize_face_asset.py) の処理を呼び、顔検出を確認して1200×1600 PNGへ保存する。元画像名、元画像・プロンプト・正規化処理・保存画像のSHA-256をレコードに記録する。元画像は内蔵ツールの保存先に残し、比較ページが参照する正規化画像はリポジトリへ保存する。

`female_054` は最初の正規化画像の下端に襟ぐりの反復が見つかったため、胸元まで広めに写す指示を加えて再生成した。最終レコードには修正後の全プロンプトを保存し、最初の生成記録と再生成理由は `previous_attempts` に残す。

## 比較ページ

各タイプに3文字コード、表示名、元の分類名を示し、その下に既存5人と追加5人をそれぞれ並べる。性別・タイプ・既存／追加で絞り込みでき、顔中心での拡大比較にも対応。写真をクリックすると原寸比率の拡大表示となり、前後ボタン・左右矢印・Escapeが使える。JavaScriptが無効でも全160枚の一覧と原寸リンクは読める。

HTMLは [テンプレート](../scripts/templates/face_additions_gallery.html) とレコードから生成する。診断画面からリンクしない確認専用ページとし、検索エンジンには `noindex, nofollow` を指定する。

```bash
python3 scripts/check_face_additions.py
python3 scripts/build_face_additions_gallery.py
python3 scripts/build_pages.py
```

ビルドの整合性検査は、既存232画像に加えて生成記録と一致する今回の追加80画像だけを許可する。以前に削除した顔セットや記録のない画像は引き続き検査エラーとなる。

```bash
python3 -m http.server 8000 --directory dist
# 別ターミナルで実行
node scripts/check_face_additions_gallery.cjs
```

ブラウザ検査では160枚の読み込み、16タイプ各10枚、既存／追加の切り替え、拡大操作、1600・900・390pxでの表示、JavaScriptなしでの閲覧を確認する。目視確認用のタイプ別スクリーンショットは `/tmp/type-checker-additions-review/` に保存する。年齢感やタイプの印象、人物同士の似方には主観が含まれるため、この一覧で採用前に確認する。

## 制作時の検証結果

追加80人の件数・タイプ・サイズ・生成記録・ハッシュ検査、サイト全体の整合性検査とPagesビルド、既存33テスト、比較ページのブラウザ検査が通過した。男女全16タイプを既存写真と並べて目視確認し、制作確認の `review_status` を `checked` にした。これは診断への採用を意味せず、状態は `preview-only` のままとする。
