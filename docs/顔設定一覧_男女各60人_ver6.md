# 顔の設定一覧：男女各60人 ver6

[HTMLで設定を比較する](顔設定一覧_男女各60人_ver6.html)

ver5の試作がよい方向というユーザーの評価を受け、男女それぞれ60人分の設定を作成した。今回は設定と一覧HTMLの作成で、追加画像は生成していない。

## 人物の構成

- 各性別の001〜010：ver5の試作10人の形態26項目と髪型を維持。参考写真を各人の詳細から確認できる。
- 各性別の011〜060：輪郭・目・眉・鼻・口・髪の新しい組み合わせ50人。
- 全員が架空の成人日本人27歳。整った容姿、自然な頬の厚み、小ぶりな丸顔、口と唇は小〜中程度。
- 数値は生成目標であり、写真の実測値・美しさの点数ではない。基準写真の数値も未校正。

既存の40人計画から、今回の明示的な依頼に合わせて60人計画を別バージョンとして作成した。40人版の本番データと、ver5の試作記録・画像はそのまま残す。

## 配分

男女で同じ分類・数値定義・派生タグ計算式を使う。各性別60人に対して次の人数になるよう、先頭10人を固定して残りを配分した。

| 項目 | 1種類あたりの人数 |
| --- | --- |
| 輪郭8種類 | 丸型・短い卵型・卵型・面長卵型は各8人、ベース型・長方形・逆三角型・菱形は各7人 |
| 目の形5種類 | 各12人 |
| 目尻の傾斜5段階 | 各12人 |
| 一重・奥二重・二重 | 各20人 |
| 目の大きさ・間隔、下まぶたの膨らみ | それぞれ3段階、各20人 |
| 眉の傾斜・曲率・太さ・目との距離 | それぞれ3段階、各20人 |
| 鼻筋・鼻幅・鼻先 | それぞれ3段階、各20人 |
| 口幅・唇の厚み・上唇の配分・中央の山 | それぞれ3段階、各20人 |
| 髪型3種類 | 各20人 |

頬の膨らみは0.51〜0.56、口の横幅と唇の厚みは0.50以下に制限する。輪郭を構成する9項目は、形が矛盾しないよう8種類の組として扱う。他の部位は固定的な組み合わせを減らすように並べ替える。これは計画上の配分調整であり、統計的独立性や生成画像の識別性を保証するものではない。

カテゴリの境界値は再作成スクリプトの `LEVELS` に定義し、HTMLの「設定値の読み方と配分」に表示する。先頭10人の細かな値は維持し、追加50人は各カテゴリの代表値を使う。日本語の説明と生成プロンプトも同じ区切りから作成する。

## HTMLの使い方

- 「特徴で見る」：人物ごとの輪郭、目、眉、鼻、口、髪を日本語で一覧表示。
- 「数値で見る」：形態26項目を比較。部位別または派生タグ10項目にも切り替えられる。
- 性別・輪郭・目の形・まぶた・IDや特徴の検索で絞り込める。
- IDを押すと、全26項目の数値と両端の意味、参考写真、派生タグ、生成プロンプトを表示。
- 表示中の人物をCSV保存でき、全60人のJSONも性別ごとに取得できる。

設定一覧は制作確認用。診断中の顔選択カードには設定値やラベルを表示しない。

## 保存形式と再作成

- [女性60人のJSON](../data/plans/female_faces_v6.json)
- [男性60人のJSON](../data/plans/male_faces_v6.json)
- [共通の形態26項目・派生タグ式](../data/plans/feature_schema_v3.json)
- [再作成スクリプト](../scripts/build_face_plan_v6.py)

各レコードは `id`、`gender`、`image`、`label`、`tags`、`prompt` と形態・髪型・設計元などを持つ。今回は未生成のため `image=null`。`planned_image` は `assets/planned/v6/<gender>/<id>.png` という将来の保存予定先。先頭10人のみ `reference_image` にver5の実在画像を持ち、今回の生成済み画像としては扱わない。

HTMLは全設定とCSS・JavaScriptを内包し、ファイルを直接開いても検索・比較できる。参考写真とJSONダウンロードには、リポジトリ内の相対位置を維持する。

```bash
python3 scripts/build_face_plan_v6.py
python3 scripts/check_integrity.py
```

計画作成は固定シードで再現可能。基準のver5計画のSHA-256を各JSONに保存する。HTMLは同じJSONデータを埋め込み、一覧と保存データが食い違わないよう整合性検証に含める。

## 確認結果

- 120人全員で形態26項目の完全重複なし。先頭10人ずつはver5の設定と一致。
- 輪郭・目・眉・鼻・口・髪の配分、共通制約、派生タグ、日本語説明と生成指示、HTMLとJSONの一致を検証済み。
- 再作成時の計画JSON・HTMLのハッシュ一致を確認。
- ブラウザで全120人、性別60人ずつ、末尾060、複数条件の絞り込み、ID検索、26項目の詳細、数値表・タグ表示、空の検索結果を確認。
- CSVは絞り込んだ女性一重20人で、形態26項目・タグ10項目・プロンプトを保存できることを確認。
- 幅390pxの画面・詳細に横のはみ出しなし。比較表の内部だけ横スクロール可能。ローカルファイルを直接開く場合も動作し、ブラウザ例外・HTTPエラーなし。
