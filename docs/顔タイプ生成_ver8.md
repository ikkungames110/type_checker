# 顔タイプ画像 ver8 — 25歳・男女各8タイプ×5人

[80枚の比較HTML](face-types-v8.html) / [女性の全プロンプト](../data/female_faces.js) / [男性の全プロンプト](../data/male_faces.js)

前回のver7ではタイプ間で見た目の年齢が異なっていたため、全員を25歳前後にそろえて80人を新規生成した。男女それぞれ8タイプ・各タイプ5人。人物ごとに内蔵 `image_gen` を1回ずつ呼び出し、80枚を個別の写真として生成した。

## 年齢と人物の違い

全レコードの `age` を25に固定し、全プロンプトの冒頭・人物設定・末尾でも25歳を指定した。「エレガント」「クール」の違いは顔の印象と骨格で表し、年齢を上げて区別しない。深いしわ、目袋、こけた頬、白髪、ひげの影などに頼らず、自然な肌の質感を残した25歳の顔を生成目標とする。

80人全員の人物設定を生成前に用意した。各タイプ内でも顔全体の形、目の印象、鼻と口のバランスが異なる5人を指定し、髪型を隠しても別人と分かることを目標とした。設定文章は `identity_brief`、実際に使用した全指示は `prompt` に保存した。特徴量の数値化・採点用タグは作成していない。

共通の撮影条件は正面、目線の高さ、ニュートラルな薄いグレーのスタジオ背景、柔らかな照明、無地のアイボリーの服、控えめな閉口表情。全員架空の成人日本人を指定し、実在の芸能人名・写真は生成に使用しない。

## 保存・取り込み

採用後の画像は `assets/<gender>/<id>.png`、データは `data/<gender>_faces.js`。比較ページも同じ本番画像を参照する。各画像は既存の [normalize_face_asset.py](../scripts/normalize_face_asset.py) で1200×1600・顔中心に正規化する。

```bash
python3 scripts/build_pages.py
```

取り込み時に元画像ファイル名・元画像と正規化画像のSHA-256・使用プロンプトのSHA-256・顔検出結果を `generation` に記録する。画像生成は内蔵ツールのみを使用し、CLI/API経由での生成やコラージュの分割は行わない。

比較HTMLではタイプごとに5枚を並べ、性別・タイプによる絞り込み、タイプ名の非表示、顔の拡大比較、原寸表示を利用できる。本番の採点入力は `type` のみで、選択したタイプに1点を加える。最多得票のタイプと、そのタイプ内で実際に選ばれた写真を結果に表示する。

## 確認結果

- 80レコードに80枚が対応し、全員の年齢設定が25。元画像ファイル名・元画像ハッシュも80件すべて異なる。
- 全80枚で顔検出に成功し、1200×1600のPNGへ正規化。画像・プロンプトのハッシュとローカルリンクの整合性検査を通過。
- 全16タイプを5枚ずつ顔の拡大表示で目視確認し、年齢感、タイプの印象、タイプ内の人物差を確認。見た目の年齢や分類は主観を含む。
- ブラウザ幅1600・900・390pxで、80枚の読み込み、各タイプ5枚への絞り込み、タイプ名非表示、拡大、前後移動、キーボード操作、横はみ出しがないことを確認。
- `npm test` と `python3 scripts/build_pages.py` が成功。

## 本番適用

80枚を本番に採用し、旧本番・旧試作・旧共有画像を削除した。トップは女性・男性ともID 011を使用。宣材画像も内蔵image_genで人物をfemale_011に差し替え、[生成プロンプトと画像の記録](../data/promotion_card.json)を保存した。結果共有カード80枚を本番写真から書き出し直している。

最初の20組で40枚を一巡し、すべて異なるタイプの二択にする。「どっちもタイプじゃない」は両タイプを記録し、21組目から除外する。7タイプ以上が除外された場合は以降の制限を解除する。診断は20回の肯定選択で終了し、スキップは加点しない。
